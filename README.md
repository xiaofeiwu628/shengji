# 自动建模平台前端重构升级 升级为vue3+TS+组合式api 
重构代码，使用TS和组合式api
业务 JS 文件迁移为 TS
新组件和重构组件统一采用 Vue3 组合式 API，更灵活，利于大型项目维护。
把vuex变为pinia
主页，注册，登录等组件也完成了组合式api和TS迁移

# 部署与运行

安装依赖，修改配置文件、把所有代码中的192.168.....的IP都改成需要部署的主服务器（FastAPI）IP
```
npm i 
```

在本地生成dist文件夹，将dist文件夹移到部署目录下(部署)
```
npm run build
```

本地运行
```
npm run serve
```
